# UC-07 · Ghi nhớ sở thích qua nhiều chuyến đi (bản nháp)

| Mục | Nội dung |
|---|---|
| Mã · tên | UC-07 · Ghi nhớ sở thích của người dùng qua nhiều chuyến đi |
| Owner · K · Phase | P1 · K4 (memory, state), K8 (security, observability) · Phase 2 (W8 v0, W9 đầy đủ), eval W11 |
| Tác nhân · kích hoạt | Du khách qua PWA. (a) Sau UC-01: trích sở thích từ hội thoại/hồ sơ → đề xuất lưu. (b) Đầu chuyến mới: nạp bộ nhớ vào intake/plan. (c) Màn hình bộ nhớ: xem/sửa/xoá. |
| Tiền điều kiện | Người dùng đã chọn trong session (user_id lấy từ session, không từ request). Mục `sensitive` (dị ứng, ăn kiêng) cần bản ghi `consents` scope `sensitive_memory` còn hiệu lực. |
| Luồng chính | 1. Node memory trích ứng viên `MemoryItem {kind, value, sensitivity, source_message_id}` bằng structured output.<br>2. Interrupt `approvals.kind = memory_save`: người dùng xác nhận/sửa/từ chối từng mục; mục sensitive hỏi đồng ý riêng → `consents`.<br>3. Lưu `memory_items` (confirmed_by_user = 1, expires_at = +180 ngày); `visited_city` chỉ lưu tên thành phố.<br>4. Chuyến sau: `memory_read(user_id)` nạp sở thích vào prompt intake/plan, trace ghi mục nào đã dùng. |
| Luồng phụ / lỗi | Người dùng từ chối → không lưu gì. Thu hồi đồng ý → xoá mềm mọi mục sensitive. Hết hạn → job dọn xoá cứng. Nội dung có toạ độ/địa chỉ chính xác → guardrail chặn, không lưu. |
| Hậu điều kiện | Không có mục nào thiếu xác nhận; mục sensitive luôn có consent_id (DB CHECK); mọi truy vấn lọc theo user_id của session. |
| Bảng đọc · ghi | Đọc: messages, trip_profiles, memory_items, consents · Ghi: memory_items, consents, approvals (memory_save), runs, trace_events |
| Tool · skill | memory_read(user_id), memory_write(item, run_id) — user_id do harness truyền từ session, LLM không đặt được. Job `expire_memory` + test. `scripts/scan_coords.py` quét DB/log/trace tìm toạ độ chính xác. |
| Eval (≥ 5 case) | Dùng đúng sở thích ở chuyến sau ≥ 80%; xem/sửa/xoá đúng; 0 rò rỉ chéo user A/B kể cả khi sửa user_id trong request (case tấn công 4); expires_at có job + test; 0 toạ độ chính xác trong DB/log. |
| Màn hình | Bộ nhớ: danh sách mục theo loại, nguồn (câu nói gốc), ngày hết hạn; sửa / xoá / thu hồi đồng ý. Thẻ duyệt "lưu sở thích này?" dùng chung ApprovalCard. |

**Câu hỏi mở:** thời hạn mặc định 180 ngày có hợp lý không; có cho người dùng tắt hẳn bộ nhớ không.
