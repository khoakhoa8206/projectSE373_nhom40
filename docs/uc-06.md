# UC-06 · Nhóm agent review lịch trình (bản nháp)

| Mục | Nội dung |
|---|---|
| Mã · tên | UC-06 · Nhóm agent planner – local expert – budget – safety review lịch trình |
| Owner · K · Phase | P1 · K6 (multi-agent), K7 (verification) · Phase 3 (W10) |
| Tác nhân · kích hoạt | Orchestrator trong graph. Kích hoạt khi itinerary của UC-02 vừa đạt `status = validated`. |
| Tiền điều kiện | Có itinerary + slot đã qua validator; dữ liệu POI, vùng hạn chế, ma trận di chuyển, weather_snapshots của run đã có. |
| Luồng chính | 1. Orchestrator gửi itinerary + profile cho 3 reviewer chạy song song: **local_expert** (thứ tự hợp lý, giờ mở cửa, trải nghiệm địa phương), **budget** (tổng chi do code cộng, khoản chưa có giá), **safety** (vùng hạn chế, thời tiết, trẻ em, mức đi bộ).<br>2. Mỗi reviewer chỉ có tool **đọc**, trả `ReviewReport {verdict, findings[{slot_ref, severity, rule, message, suggestion}]}` (structured output).<br>3. Code kiểm `slot_ref` phải là slot có thật, rồi ghi `review_reports` + `review_findings`.<br>4. Có `request_changes` và `review_rounds < 2` → gửi findings về plan → validator → review lại.<br>5. Cả 3 approve hoặc đủ 2 vòng → `itineraries.status = reviewed`, chuyển sang verify (UC-11). |
| Luồng phụ / lỗi | Reviewer lỗi/timeout: ghi trace `error`, coi như không có ý kiến, không chặn luồng. slot_ref không tồn tại: bỏ finding, ghi trace `guardrail`. Quá 2 vòng: giữ bản tốt nhất, findings chưa xử lý hiện trên màn hình review. |
| Hậu điều kiện | Mỗi vòng có đúng 3 `review_reports`; `review_rounds ≤ 2`; mọi finding trỏ slot có thật; reviewer không ghi được bảng nghiệp vụ nào. |
| Bảng đọc · ghi | Đọc: itineraries, itinerary_slots, trip_profiles, pois, restricted_zones, travel_matrix, weather_snapshots · Ghi: review_reports, review_findings, itineraries.review_rounds/status (orchestrator), runs, trace_events |
| Tool · skill | Reviewer: get_poi, get_opening_hours, get_travel_time, check_restricted_area (chỉ đọc; quyền khai trong `config/permissions.yaml`, harness chặn tool ngoài danh sách). Coordination trace: mọi thông điệp orchestrator ↔ reviewer ghi `trace_events` (node = `reviewer.<tên>`). |
| Eval (≥ 5 case + ≥ 10 lịch trình lỗi cài sẵn) | Bắt ≥ 75% lỗi cài sẵn (precision/recall theo rule); slot_ref đúng 100%; ≤ 2 vòng; reviewer gọi tool ghi → bị chặn (case quyền); so sánh tỉ lệ qua validator khi có/không có reviewer; case tấn công 2 (xin đường tắt vào khu quân sự) bị safety chặn. |
| Màn hình | Kết quả review theo từng agent (verdict, findings gắn với slot) + coordination trace dạng dòng thời gian. |

**Câu hỏi mở:** reviewer dùng cùng model với planner hay model rẻ hơn; findings mức `low` có bắt planner sửa không.
